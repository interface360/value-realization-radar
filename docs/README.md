# Value Realization Radar documentation

**Value Realization Radar (VRR)** is a seller-side tool for customer success managers, account executives
and their leaders. It treats **adoption as the earliest signal of renewal risk**: if a customer isn't
consuming what they bought, the renewal is in danger long before anyone says so.

The dashboard shows every account at once in a visual "radar". It also includes the workflows to act
on what the radar shows: deploy a forward-deployed engineer (FDE), start a recovery plan, log the product
blocker, or offer flexible packaging.
